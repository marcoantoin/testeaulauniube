Ordem básica para diagnosticar um problema em um computador

  1. Verificar se o computador está recebendo energia pelos cabos de conexão
  2. Verificar cabeamento tanto do computador quanto do monitor
  3. Verificar a memória RAM
  4. Verificar o HD ou SSD, barulho ou lentidão no sistema
  5. Verificar sistema operacional, travamentos lentidão, reinícios
  6. Realizar testes de mesa
